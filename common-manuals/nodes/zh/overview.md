# Cybion 公共手册

这是 Cybion 自带的操作指南：随 Cybion 源码（仓库 `common-manuals/` 目录）编译发布，所有用户共享、只读；控制器不存储、不在运行时修改它，内容变更只随版本发布——源码公开，可自行审阅修订历史。

你（AI）在需要「如何用 Cybion 自身功能干活」的指导时，按需逐层阅读；不必一次读完，也不要把它当作当前用户的数据——它是产品知识。

优先级：引擎行为与工具契约以每次请求携带的工具描述为准；本树提供使用方式、配方与坑。两者冲突时，以工具描述和实际行为为准。

## 两个钩子

Cybion 期望每个用户长期维护两份用户手册：**项目索引**（项目在哪、是什么）与**价值偏置**（冲突时他会怎么选）。它们不靠用户自觉，靠你在干活的过程中顺手维护：位置出现或变化时补一行索引，出现真实取舍时记一条偏置。有需要时可以直接建这两份手册（一句话告知即可），用户删掉则不重建。写法与格式见对应节点。

当前主题：

- **终极机器**：在 Worker 上按期执行一条检查命令、失败时请绑定的 Thread 修复的沉默看门机器。
- **Linkit**：Linkit 与 Cybion 的关系（身份、通知与触达），以及为什么模型侧没有 linkit_* 工具。
- **加载手册**：某份手册要跨轮次、跨压缩一直用下去时，用 `load_manual` 把它挂到本 Thread 上——控制器会在每次请求里带上它的最新副本，内容被改或历史被压缩后自动补发，不需要再调工具；不再需要时用 `unload_manual` 释放，副本留到下次压缩自然退休。
- **项目索引**：把用户的项目记成「名称 | 位置 | 简介」的导航清单；只做路由，不写状态。
- **价值偏置**：捕捉用户在真实取舍上的选择，记成可执行判据；下次先用，用完给他推翻的机会。
- **用户手册格式**：这类由 Agent 维护的用户手册该长什么样——一行一条、字段固定、增改不重写、收敛到约 60 行。
