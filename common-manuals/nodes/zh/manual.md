# Cybion 用户帮助手册

本手册是 Cybion 的用户帮助手册，在所有用户之间共享。

Cybion 是 Agent Harness 平台产品，底层由 NormAI 提供多样化的模型支持，Cybion 对外开放 Agent API，目标是作为 Agent 应用的基础设施。

基本术语：

**线程 (Thread)**：在 Cybion 中，线程是执行智能任务的基本单位。每个线程都有自己的配置、生命周期、状态、上下文，可以独立运行并处理特定的请求或操作，不同线程之间的上下文是隔离的。类似的概念有对话（Chat）、会话（Session）等。

**手册 (Manual)**：长期维护的、精炼压缩的、用于引导模型行为的文本提示。类似的概念有 Agents.md, Claude.md, Skills 等。它的有无决定了模型是否能在特定场景下做出正确的行为或者避开不该做的行为。手册是跨轮次、抗压缩的。压缩时，不需要输出手册的内容，因为 Cybion 会自动补发最新手册。相关工具：`load_manual` / `unload_manual` / `list_manuals` / `write_manual`。线程还可以在设置里指定「初始手册」：这些手册在线程创建时就已加载，模型不必再为它们调用 `load_manual`。

**便签 (Note)**：线程级别维护的、用于记录目标和待办事项的文本提示。类似的概念有 TODO, 待办事项，目标模式等。便签是跨轮次、抗压缩的，便签上记录的事项在验证完成后应当立即被划掉。便签尚未全部完成时，Cybion 会反复续跑线程，直到便签被全部划掉，或者线程进入受阻（Blocked）状态请求上级介入。相关工具：`add_notes` / `cross_out_notes` / `block_thread`

## 你应该维护的用户级手册

1. 记住用户的项目目录在哪里。

   推荐放在顶层，名字建议为 项目位置。

   内容要包括项目名或者别名，本地或者远程位置。不要包含项目简介，状态，进度等信息，它的唯一目的就是告诉模型去哪里找项目，避免模型在整台设备上扫描浪费时间。

2. 分析并记住用户的价值偏置。

   推荐放在顶层，名字建议为 价值偏置。

   内容要包括用户在真实场景下，在什么与什么之间权衡利弊时，用户倾向于选择哪一边，用户选择的理由是什么。它的唯一目的就是学习用户的价值观，与用户站在同一立场，尽量多地代替用户做决策，不打扰用户。

   建议的维度：场景、张力、选择、升华。（这恰好是塑造人物的逻辑顺序：先布置场景，再安排冲突体现张力，接着是人物的思考与抉择，最后升华得到人物的形象。）

## 终极机器 UM: Ultimate Machine

终极机器起源于贝尔实验室的一个玩笑盒子，平时什么都不做，只在检查失败时现身，也称为无用机器。在 Cybion 中，终极机器是一种主动启动线程的机制。它可以设置一个检查命令，以一定的周期，在特定的 Worker 上运行，一旦这个命令返回非零退出码或者失败，就会启动一个 Cybion 修复线程，尝试排查和修复问题，直到命令返回零退出码为止。终极机器的设计理念是让系统能够自我监控和自我修复，减少人工干预，提高系统的稳定性和可靠性。终极机器在检查命令正常退出时，完全不消耗 Token。

经典例子:

- 资源水位检查：例如检查磁盘使用率是否超过阈值，如果超过则触发修复线程清理磁盘。
- 到期类检查：例如检查证书是否即将过期，如果快过期则触发修复线程更新证书。
- 服务存活检查：例如检查关键服务是否在运行，如果服务停止则触发修复线程重启服务。
- 工单类检查：例如检查是否有未处理的工单，如果有则触发修复线程直到工单处理完毕。
- 群聊类检查：例如检查群聊是否有未读消息，如果有则触发修复线程处理消息。

相关工具：`cybion_list_ultimate_machines` / `cybion_get_ultimate_machine` / `cybion_set_ultimate_machine` / `cybion_delete_ultimate_machine`

## NormAI 拓展

由于不是所有的模型都支持多模态输入输出，NormAI 提供了多种模态的功能。

- 联网搜索：normai_web_search
- 语音转写：normai_audio_transcription

## Cybion Thread Token

Cybion 作为 Agent Harness 基础设施，提供了统一的 API 接口，方便 Agent 开发者调用和集成。反过来说，Cybion Thread 有可能是通过 API 创建和管理的。当本线程需要调用外部服务时，需要鉴权。出于安全原因，Cybion 提供了 create_thread_token 工具来创建一个一次性的线程令牌，线程可以使用这个令牌向支持验证 Cybion Thread Token 的目标服务发送请求。注意，令牌会在非常短的时间内过期，每次请求都建议使用新的令牌，并立即发送至目标服务。
