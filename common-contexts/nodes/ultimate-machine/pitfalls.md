# 边界与坑

- **丢消息 ≠ 坏掉**：修复 Thread 忙时失败消息被丢弃（非排队）；静默既不代表健康，也不代表机器死了。
- **离线只提醒一次**：Worker 离线（或已被删除）时经 Linkit 提醒一次，长中断期间保持安静，恢复后继续。
- **失联判定**：运行 15 分钟未落定即判失联（设备中途死亡等），提醒一次，下个间隔重试。
- **暂停 ≠ 删除**：`enabled=false`（或 `cybion_set_ultimate_machine` 传 `enabled=false`）只是暂停；彻底移除请删除绑定的修复 Thread 或它使用的 Worker。
- **改绑 Worker**：会重启「离线提醒」事件（视作新的一轮）。
- **重命名**：机器改名会同步修复 Thread 标题；手动改过标题的除外。
- **敏感信息**：失败输出会进入 Thread 历史——不要 echo 密钥/令牌；确需检查令牌有效性时，只输出布尔判断。
- **环境差异**：命令由 Worker 的执行环境运行；不要假设 PATH、locale、时区一致。
- **间隔语义**：下一次运行 = 上次落定 + 间隔，因此慢命令会拉长实际周期；同一机器同时最多一次运行。
