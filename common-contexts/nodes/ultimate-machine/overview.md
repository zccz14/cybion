# Ultimate Machine（终极机器）

一台终极机器 = 一个 Worker + 一条 bash 检查命令 + 一个运行间隔。它按期运行：返回 0 就保持沉默；失败时，控制器把修复请求投递到它绑定的修复 Thread（标题形如「终极机器 · <名称>」）。

名字来自贝尔实验室的玩笑盒——那台唯一的功能就是把自己关掉的机器。这里的机器延续同一种幽默：平时什么都不做，只在检查失败时现身；命令回到 0 之后，再次安静下来。

关键语义：

- **调度**：创建后立即执行第一次；之后每次运行在「上一次运行落定 + 间隔」时开始，同一台机器同时最多一次运行。
- **失败**：exit ≠ 0（或命令被杀）→ 修复 Thread 收到一条用户消息：命令、exit、输出尾部、意图（若有）与成功判据「使该命令返回 0」。
- **离线**：运行时刻 Worker 离线或已不存在 → 跳过本次，通过 Linkit 提醒一次；恢复后自动继续（每个离线事件只提醒一次）。
- **失联**：一次运行 15 分钟仍未落定（设备中途死亡等）→ 判定失联，提醒一次，下个间隔重试。
- **丢消息**：修复 Thread 正在运行时，新的失败消息会被丢弃（不是排队）——它会在下一次运行落定后重新决定是否投递。
- **生命周期**：删除绑定的修复 Thread 或它使用的 Worker，会随之删除机器；改绑 Worker 会重启离线提醒事件。
