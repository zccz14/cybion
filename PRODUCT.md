# Product

## Register

product

## Platform

web

## Users

An operator who needs an AI to complete consequential work across a set of
heterogeneous machines. They work in a browser, often moving between a local Mac
and remote Linux hosts, and need an accurate view of which machine will act.

## Product Purpose

Cybion turns OpenAI-compatible models into an unrestricted operational harness.
It connects a human, an AI, and every enrolled machine through one web console.
Success is a user reaching a real machine-wide outcome without manually managing
project roots, sandboxes, or a collection of separate agent sessions.

## Positioning

One continuous AI operating surface for every file and machine the operator owns.

## Brand Personality

Direct, composed, and infrastructural. The interface should feel like a precise
control room: it makes powerful scope explicit without theatrical danger styling.

## Anti-references

Avoid generic chat SaaS dashboards, cute autonomous-agent mascots, fake terminal
chrome, and permission-theater that suggests constraints Cybion does not have.

## Design Principles

- Make the active machine and action boundary unmistakable.
- Keep the conversation central; surrounding controls support action rather than compete with it.
- Prefer a compact operational vocabulary over novelty.
- Reveal capability through real status and artifacts, not decoration.

## Accessibility & Inclusion

Keyboard-operable controls, visible focus states, high-contrast text, reduced
motion, Chinese/English UI text, and an explicit light/dark theme control are
baseline requirements.
